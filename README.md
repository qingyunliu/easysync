# EasySync - 通用数据同步平台

**EasySync** 是一个开源的企业级文件同步系统，支持对象存储（OBS）、NAS 和 NFS 之间的数据双向同步，适用于数据迁移、灾备同步、存储整合等场景。

## 🚀 项目亮点

- 支持 **OBS ↔ OBS、NFS ↔ NAS、NAS/NFS ↔ OBS** 的灵活同步模式
- 多用户系统，支持权限管理与隔离
- 同步任务支持多线程并发与调度执行
- 支持同步节点与客户端管理、挂载与状态监控
- 实时展示同步进度与日志
- 基于 `rsync` 和 `rclone` 构建核心同步能力

## 🛠️ 快速开始

### 安装要求

- Python 3.9+
- Node.js 18+
- MySQL 5.7+
- 安装 rsync 和 rclone
- Redis（可选，用于任务调度）

### 后端部署

```bash
git clone https://github.com/your-org/EasySync.git
cd obsync/backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python manage.py db upgrade
python manage.py run
```

### 前端部署

```bash
cd obsync/frontend
npm install
npm run dev
```

## 📘 REST API 示例

| 方法   | 接口路径            | 描述                    |
|--------|---------------------|-------------------------|
| POST   | /api/login          | 登录，返回 JWT Token    |
| GET    | /api/nodes          | 获取同步节点列表        |
| POST   | /api/tasks          | 创建同步任务            |
| GET    | /api/tasks/{id}     | 获取任务详情与进度      |
| POST   | /api/storage/mount  | 挂载 NFS/NAS 路径       |
| POST   | /api/clients/heartbeat | 客户端心跳上报        |

完整 API 文档请见：`/docs/api-spec.md` 或 Swagger 文档页面。

## 🧱 数据模型设计（简略）

- users：用户信息表（含权限）
- clients：同步客户端
- nodes：同步节点（控制端）
- tasks：同步任务配置
- jobs：任务运行实例与状态
- storages：NFS/NAS/OBS 配置
- logs：任务执行日志
- audit_logs：操作审计记录

### 系统要求

#### 硬件要求
- CPU: 4核心及以上
- 内存: 8GB及以上
- 存储: 根据同步数据量决定，建议预留50%空间
- 网络: 千兆网络，支持外网访问

#### 软件要求
- 操作系统: Linux (推荐 Ubuntu 20.04+ / CentOS 8+)
- Python 3.9+
- Node.js 18+
- MySQL 5.7+
- Redis 6.0+（可选）
- rsync 3.1+
- rclone v1.55+

### 故障排查

常见问题及解决方案：
1. 同步任务失败
   - 检查网络连接
   - 验证存储权限
   - 查看详细日志
2. 性能问题
   - 检查系统资源
   - 优化同步配置
   - 调整并发参数
3. 存储挂载问题
   - 验证挂载点
   - 检查权限设置
   - 确认网络连通性
