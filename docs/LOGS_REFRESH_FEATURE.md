# 任务日志自动刷新功能

## 🎯 功能概述

为任务日志页面添加了智能的自动刷新功能，用户可以自定义刷新间隔，实现平滑的数据更新体验。

## ✨ 主要特性

### 1. 可配置的刷新间隔
- **关闭刷新**: 手动刷新模式
- **3秒**: 高频刷新，适合实时监控
- **5秒**: 标准刷新，平衡性能和实时性
- **30秒**: 低频刷新，减少服务器压力
- **1分钟**: 长间隔刷新，适合后台监控
- **5分钟**: 超长间隔刷新，适合长期任务

### 2. 智能刷新机制
- **防重复请求**: 避免在加载时重复发送请求
- **平滑更新**: 只更新数据，不刷新整个页面
- **状态指示**: 实时显示倒计时和刷新状态
- **自动停止**: 对话框关闭时自动停止刷新

### 3. 用户体验优化
- **持久化配置**: 刷新间隔设置保存到本地存储
- **视觉反馈**: 刷新按钮显示当前状态和倒计时
- **智能启动**: 打开日志时自动应用之前的刷新设置

## 🔧 技术实现

### 核心组件
- `logsRefreshInterval`: 刷新间隔配置
- `logsAutoRefresh`: 自动刷新状态
- `logsRefreshCountdown`: 倒计时显示
- `logsRefreshTimer`: 定时器管理

### 主要方法
```javascript
// 启动自动刷新
startLogsAutoRefresh(interval)

// 停止自动刷新
stopLogsAutoRefresh()

// 切换自动刷新状态
toggleLogsAutoRefresh()

// 处理间隔变化
handleLogsRefreshIntervalChange(interval)
```

### 数据持久化
```javascript
// 保存配置到本地存储
localStorage.setItem('logsRefreshInterval', interval.toString())

// 从本地存储读取配置
const logsRefreshInterval = ref(parseInt(localStorage.getItem('logsRefreshInterval') || '0'))
```

## 🎯 使用场景

### 实时监控
- **3-5秒刷新**: 适合正在运行的任务
- **实时进度**: 查看同步进度更新

### 后台监控
- **30秒-1分钟**: 适合长时间运行的任务
- **资源友好**: 减少服务器压力

### 历史查看
- **关闭刷新**: 查看已完成任务的历史日志
- **手动刷新**: 按需更新数据

## 🔄 刷新流程

1. **用户选择间隔**: 从下拉菜单选择刷新间隔
2. **保存配置**: 配置保存到本地存储
3. **启动定时器**: 根据间隔启动倒计时
4. **倒计时更新**: 每秒更新倒计时显示
5. **执行刷新**: 倒计时归零时执行数据刷新
6. **重置倒计时**: 重新开始倒计时循环
